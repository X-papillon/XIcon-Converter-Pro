# <img src="https://images2.imgbox.com/eb/8b/abpFSJrE_o.png" width="50"/> XIcon-Converter-Pro
### A powerful, fully offline Chrome Extension for converting images into PNG, ICO, and full Favicon Packs.

![Version](https://img.shields.io/badge/version-4.0-blue)
![Manifest](https://img.shields.io/badge/manifest-v3-orange)

![Status](https://img.shields.io/badge/status-Active-success)

## Features 🚀

🔥 SmartEdge Background Removal (local detection – no API required)

- 🖼 PNG Export (custom size)

- 🎯 ICO Generator (Single Size)

- 🧩 True Multi-Layer ICO (16–256)

- 🌐 Full Website Favicon Pack (ZIP)

- 📦 Auto-generated site.webmanifest

- ⚡ 100% Offline Processing

- 🎨 Dark Neon Pro UI

- 💾 Keeps Original File Name

---

## 🖼 Supported Exports 

### PNG

* Custom selectable sizes

* High quality output

* Transparent background supported

### ICO

* Single size ICO

* Multi-size ICO (16, 32, 48, 64, 128, 256)

### Favicon Pack (ZIP)

- Includes:

* favicon.ico

* favicon-16x16.png

* favicon-32x32.png

* apple-touch-icon.png

* android-chrome-192x192.png

* android-chrome-512x512.png

* site.webmanifest

---

## 🧠 SmartEdge Background Removal

- The SmartEdge engine:

* Detects background color from image corners

* Calculates color distance

* Applies edge protection to preserve object

* Removes background without destroying subject details

* Works completely offline

No AI APIs
No external servers
No data leaving your device

## 🛠 Installation (Chrome Extension)

1.Download or clone this repository

2.Open Chrome

3.Go to chrome://extensions/

4.Enable Developer Mode

5.Click Load Unpacked

6.Select the project folder

Done ✔
